# 💻 PC Optimizer Pro – Broken Heart

**PC Optimizer Pro – Broken Heart** is a Windows system utility application built with **Python, Tkinter, and psutil** to help users monitor and manage their PC's performance and system resources.

The application provides a simple and user-friendly dashboard for monitoring CPU, RAM, disk, network, battery, and running processes, along with temporary file cleanup and other system utility features.

## 🚀 Features

* 📊 Real-time CPU usage monitoring
* 🧠 RAM & memory monitoring
* 💾 Disk/storage usage monitoring
* 🧹 Temporary file cleanup
* ⚙️ Running process monitoring
* 🌐 Network monitoring
* 🔋 Battery information
* 📈 System performance dashboard
* 🖥️ Windows system information
* 🎨 User-friendly graphical interface
* 🔄 Real-time resource updates

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **psutil**
* **Windows System Utilities**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/md-zihad-coder/PC-Optimizer-Pro-Broken-Heart.git
```

### 2. Open the project directory

```bash
cd PC-Optimizer-Pro-Broken-Heart
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

Or install `psutil` directly:

```bash
pip install psutil
```

### 4. Run the application

```bash
python main.py
```
